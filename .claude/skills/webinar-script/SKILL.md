# webinar-script

One live presentation that teaches, then sells.

## Inputs (from the brief)

- The topic, the offer it sells, and the framework to follow.
- The user's material: what the user teaches, stories, demos, proof, price, deadline.
- **Model (optional):** a past webinar to model. It sets structure only, never wording.

## Output

Slide by slide:
- **Slide:** the words on screen. Short.
- **Say:** what the user says while it's up.

Mark each framework section. Demos get a slide that names what the user shows, not a script of the clicks.

## Rules

- Write for the ear: how the user talks out loud.
- Never invent proof, prices, dates or bonuses. Flag gaps as `[GAP: what's missing]`.
