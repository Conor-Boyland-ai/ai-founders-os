# Scheduling IG stories

1. **Check what's connected.** If the user has a scheduler connected that can post Instagram stories (for example Metricool), use it. If not, skip to step 3.
2. **Schedule each story** at the day and time the user gave, in order. Images usually need a public URL first; use the scheduler's own upload if it has one.
3. **No scheduler:** put the finished `story_<n>.jpg` files in a folder named `Stories to post - <date>` and tell the user where it is.
4. **Tell the user** the date and time of each story.
