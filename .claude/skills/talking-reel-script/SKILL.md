# talking-reel-script

One reel the user films to camera.

## Inputs (from the brief)

- **Hook, topic and format.** The user chooses these. Never pick them yourself.
- **CTA:** usually a comment keyword for a lead magnet.
- **Model (optional):** a link to a reel, script or framework to model. It sets structure only, never wording.

## Output

- **Text hook:** the on-screen line, a few words.
- **Verbal hook:** the first spoken line.
- **Visual hook:** what's on screen in the first second.
- **Script:** the spoken lines, beat by beat as the format sets them.
- **Caption with CTA:** short. One more reason to act, ending on the CTA.

All three hooks say the same thing. Clarity over cleverness.

## Rules

- One idea per reel.
- Write for the ear: how the user talks out loud. No line the user'd trip over.
- Never invent facts, numbers or results. Flag gaps as `[GAP: what's missing]`.
