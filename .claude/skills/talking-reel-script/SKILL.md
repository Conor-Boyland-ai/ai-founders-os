# talking-reel-script

One reel the user films to camera, modeled on a reel that's already winning.

## Inputs

The user gives these. If one is missing, ask for it in one line.

- **Reel to model:** the outlier's link, or its hooks and script from their research page. Read its full script.
- **What they want to say:** their remix notes. Their point, angle, framework or story.
- **CTA keyword:** the comment keyword for their lead magnet.
- **Hook (optional):** if they wrote one, use it word for word. If not, write 3 options that follow the outlier's hook structure closely, with their topic in it.

## Steps

1. Map the outlier's script beat by beat: what each part does and how long it runs.
2. Write the user's script on those same beats, filled with what they want to say. Take the structure from the outlier and the substance from the user. Their version should carry more value per line than the original.
3. Add the caption and CTA.

## Output

- **Text hook:** the on-screen line, a few words.
- **Verbal hook:** the first spoken line.
- **Visual hook:** what's on screen in the first second.
- **Script:** the spoken lines, beat by beat.
- **Caption:** short, one more reason to act, ending on "Comment [KEYWORD]…".

All three hooks say the same thing. Clarity over cleverness.

## Rules

- One idea per reel.
- Write for the ear, the way the user talks out loud. Every line should be easy to say on camera.
- Use the outlier's structure, never its wording or its points. The script says what the user wants to say.
- Never invent facts, numbers or results. Flag gaps as `[GAP: what's missing]`.
