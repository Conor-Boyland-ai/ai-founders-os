# my-voice

To write like the user, read their real writing in `samples/` and copy the STYLE: rhythm, humor, sentence length, formatting and energy.

## If samples/ is empty

Stop and tell the user, in one short message: "I don't have any of your writing yet. Paste in 5–10 things you've written that sound most like you (emails, posts, captions), and I'll save them so everything I write sounds like you." Save each one they give you as its own file in `samples/` (for example `samples/email-launch.md`), then carry on.

## How to write

1. Read 3–5 samples, the ones closest to what you're writing. Do this right before drafting, so their writing is the freshest thing in context.
2. Write about the topic you were given. Take only the style from the samples, never their stories, people, facts or details.
3. Run the humanizer skill as the final pass.

## Adding samples later

When the user says "save this as a sample" or "this one sounds like me," save it to `samples/`. Never add samples on your own.
