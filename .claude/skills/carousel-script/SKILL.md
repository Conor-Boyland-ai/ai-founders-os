# carousel-script

Write the text for one carousel: numbered slides plus a caption. Text only — no visual design. If the user has past carousels they like, read them first: the finished draft must sit naturally beside them.

## Structure

- **Slide 1 (Cover):** the hook. Bold enough to stop the scroll and earn the first swipe.
- **Slide 2 (Context):** frame the problem or the promise in 1-2 sentences. Why should this reader care right now?
- **Body slides:** one point per slide. The headline carries the load; the lines under it support. Density varies — a slide handing over a full prompt or framework can run long; a slide making one point stays tight. End slides with a pull toward the next when it's genuine — never a fake tease.
- **Final slide (CTA):** land the takeaway and ask for the one action (usually a comment keyword).
- **Caption:** short. It complements the slides without repeating them and gives one more reason to take the CTA. They just read a carousel — don't make them read an essay.

## Formats

Pick the one that fits the material. Don't blend them.

1. **Listicle** — N tips, mistakes, or tools, one per slide.
2. **Framework** — a step-by-step process, one step per slide.
3. **Before/After** — the wrong way, then the right way.
4. **Data/Proof Story** — a result or number, then how it happened.
5. **Mini Case Study** — problem → approach → result → lesson.

## Writing rules

- The author's material supplies the meaning — write fresh slides that deliver it. Where material is missing, flag the gap — never invent facts, numbers, or results.
- Default when the source is a longer piece (an email, a Substack post, a transcript): distill the one key point first and write only around that. The source is raw material, not a script to compress. A brief that asks for more ("cover all 7 tips") overrides this — the brief always wins.
- One carousel = one idea. Slide count is whatever that idea needs — a 3-slide carousel that lands beats a 10-slide carousel that rambles.
- Hard limit: 10 slides. Instagram's publishing API drops anything past slide 10 when posting through a scheduler. This is a publishing limit, not a target.

## Before delivering

Put the draft next to the user's past carousels, if they have any. If any slide or the caption would look out of place beside them, fix it and compare again.
