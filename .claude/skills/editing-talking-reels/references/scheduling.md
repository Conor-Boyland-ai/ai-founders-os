# Scheduling reels

- **Check what's connected.** If the user has a scheduler connected (for example Eden or Metricool), use it. If not, leave the finished files in `final/` and tell the user they're ready to post.
- **"Post it" means the next free slot** in their schedule. Publish immediately only when the user says "now."
- **Captions:** use the caption the user approved for each reel, verbatim.
- **Comment-keyword automations** (like ManyChat) usually only work on Instagram. On other platforms, swap the "comment KEYWORD" line for a plain CTA.
- **After scheduling,** list each reel with its date and time.
