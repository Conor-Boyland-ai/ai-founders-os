# content-plan

A shortlist of options. The user decides.

## Inputs

- The latest research: outliers, news, performance, buyer language.
- The user's idea bank, their identity and messaging, and the formats the user uses.

## Output

5–10 options. Each one:
- **Topic:** one line
- **Hook:** modeled on a real outlier, written for the user's lane
- **Format:** one the user already uses
- **CTA:** the lead magnet or offer it points to
- **Evidence:** the outlier, number or buyer quote behind it
- **Criteria it hits**

## Starting criteria (the user refines these over time)

1. **Proven reach:** an outlier at 3x+ its creator's average, recently.
2. **Fit:** in the user's lane, speaking to the user's buyer.
3. **Buyer signal:** matches real buyer language.
4. **Lead path:** connects to a lead magnet or the user's offer.
5. **Their edge:** The user has a real build, story or result to show.
6. **Reach:** broad enough to pull in new people.

## Rules

- Options, never a final plan. Every option shows its evidence.
- Never invent a hook from nothing. Every hook traces to a real post or the user's idea bank.
