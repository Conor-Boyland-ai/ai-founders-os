# silent-reel-script

One reel with no talking. The words are on screen and in the caption.

## Inputs (from the brief)

- **Hook, topic and format.** The user chooses these. Never pick them yourself.
- **CTA:** usually a comment keyword for a lead magnet.
- **Model (optional):** a link to a reel, script or framework to model. It sets structure only, never wording.

## Output

- **On-screen hook:** the line that stops the scroll, readable in one second.
- **On-screen text:** any further lines, in order, only if the format uses them.
- **Caption:** carries the idea. Opens by paying off the hook, delivers the point, ends with the CTA.

## Rules

- One idea per reel.
- On-screen text is short enough to read before the clip moves on.
- Never invent facts, numbers or results. Flag gaps as `[GAP: what's missing]`.
