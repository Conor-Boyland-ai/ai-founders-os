# buyer-research

The real words of the people the user sells to.

## Inputs

- Time window (default: the last 30 days).
- Any conversations the user pastes in (DMs, comments).

## Steps

Read buyer conversations wherever they're available: email replies, sales and client call notes or transcripts, and anything the user pastes in.

## Output

Grouped by theme (questions, pains, desires, objections). Each entry:
- **Quote:** verbatim
- **Source and date**

## Rules

- Verbatim quotes only. Never paraphrase or invent a buyer line.
