# course-lesson-script

The user teaching one new student, directly. Smooth, warm and flowing, in the user's voice (my-voice skill).

Lesson shape: the result → the why → run it (the agents doing real work) → one action → CTA ("Run this, share your biggest takeaways in the group, and comment on someone else's posts to support them").

Write it freely and use your judgment. Never invent facts.
